# Database

PostgreSQL via **Drizzle ORM**. Schema: `apps/backend/src/db/schema.ts`.
Migrations: `apps/backend/drizzle/` (generated by `drizzle-kit generate`,
applied automatically at server boot).

## Tables

| Table | Purpose | Key constraints |
|---|---|---|
| `users` | Accounts | unique `email`; `role` ∈ student/moderator/admin; `college_id` FK→colleges (set null) |
| `colleges` | Institutions | unique `domain` (nullable) |
| `subjects` | Academic subjects | `college_id` nullable → `null` = shared across campuses |
| `resources` | Shared files metadata | FKs→subjects/colleges/users; unique `storage_key`; indexes on subject/college/uploader/type/created |
| `resource_votes` | Up/down votes on resources | unique `(resource_id, user_id)` |
| `resource_reviews` | Reviews & replies on resources | `parent_review_id` self-reference (nullable) |
| `review_votes` | Votes on reviews | unique `(review_id, user_id)` |
| `bookmarks` | Saved resources | unique `(resource_id, user_id)` |
| `college_reviews` | Structured college ratings | unique `(college_id, user_id)` — one active review per user per college |
| `reports` | Community reports | `target_type` ∈ resource/resource_review/college_review; `status` ∈ open/resolved/dismissed |
| `moderation_logs` | Audit trail for mod actions | actor, target, action |
| `sessions` | Server-side sessions | unique `token_hash` (SHA-256), `expires_at` |

## Enums

- `user_role`: student, moderator, admin
- `resource_type`: notes, pyq, syllabus, revision, solved, other
- `visibility`: campus, college, restricted
- `upload_status`: pending, ready, failed
- `vote_type`: upvote, downvote
- `moderation_status`: visible, hidden, removed
- `report_status` / `report_target_type` as above

## Integrity notes

- File **bytes never live in Postgres** — only `storage_key` + metadata.
- `download_count` incremented transactionally-ish on each authorized download.
- College rating aggregates are computed at read time from
  `moderation_status = 'visible'` reviews — no denormalized counters to drift.
- Deletes: votes/bookmarks/reviews cascade with their parent; users cascade;
  colleges set-null on users, cascade on college reviews.
- Users cannot self-assign roles: `role` is never accepted from request bodies.
